Objects you can click

Six small machines. Press the buttons and watch the numbers move. You do not need to read much here — the point is to see what changes, and what does not.

01

Your boss asks you to also track stock. Press the button and watch how much work each side needs.

The object side can grow without touching the function. That is the whole reason to use a box.

02

A method is just a button inside the box

Nothing exotic. A method is a function that lives inside an object instead of outside it.

{ name: "Laptop", price: 1000, stock: 3, // a function stored in the box sell() { … }, restock() { … }, }
laptop
name"Laptop"
price1000
stock3
sellbutton
restockbutton

The top three lines are what the laptop is. The bottom two are what you can do to it. Both live in the same box.

03

“this” means my own box

Both boxes below run the exact same line of code. Press each button and watch which number moves.

sell() { this.stock -= 1; } // ← both boxes share this one line
laptopthis
stock3
phonethis
stock8

Press a button. One line of code, two different results — because this changes depending on who you called it on.

04

Why not just write the name?

Here the code says the word laptop instead of this. Press phone.sell() and watch carefully.

sell() { laptop.stock -= 1; } // ← copy-pasted into BOTH boxes
laptopchanged
stock3
phonechanged
stock8

A hard-coded name always points at the same box, no matter who you called. That is a silent bug — nothing crashes, the wrong number just quietly changes.

05

To read “this”, look left of the dot

Same sentence — "Hi, I'm " + this.name — spoken by different people. Pick a speaker.

alice.greet()
greet() { return "Hi, I'm " + this.name; } // output: "Hi, I'm Alice"

this is whatever sits immediately to the left of the dot. Alice is left of the dot, so this.name is Alice's name.

06

Put it together: a box you operate by pressing buttons

This inventory object holds other objects. You never touch the list directly — you press its buttons and it looks after itself.

Notice sell("Tablet") does not crash — the box checks for itself and answers politely. The box protects its own data, so your other code does not have to.

★

Three sentences to carry forward

  • 01
    An object is a box. Put the data and the buttons that work on that data in the same box.
  • 02
    “this” means my own box. It lets one line of code work correctly for every box that holds it. Read it by looking left of the dot.
  • 03
    Write methods as sell() { }, never sell: () => { }. Arrow functions do not get their own this, so they break silently.
