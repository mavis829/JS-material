## What this lesson covers

1. Running JavaScript from an HTML file
2. `let` and `const`
3. Number operations and order of operations (PEMDAS)
4. String operations
5. Logical and mathematical operators

Note: points 4 and 5 are in the lesson *overview* but not in the lesson *body* -
the lesson hands them to the assignment articles. The companion covers them in
sections 4 and 5 so nothing is missing.

## The assignment

**Exercises** (section 6 of the companion, runnable there):

1. `console.log(23 + 97)` - should log 120
2. Add six different numbers
3. `(4 + 6 + 9) / 77` - about 0.24675
4. `let a = 10`, log it, re-assign, log again, then `let b = 7 * a`
5. `const max = 57`, `const actual = max - 13`, `const percentage = actual / max` - about 0.7719
6. Keep playing around until you are comfortable

**Reading** (section 7):

- MDN - What is JavaScript?
- JavaScript.info - Variables
- MDN - Basic math in JavaScript
- JavaScript.info - Basic operators, maths (**do the Tasks at the bottom**)

## How to get the most from this one

Type the exercises yourself before loading the starters. The whole point of
this lesson is building the habit of writing a line, running it, and reading
what came back.
